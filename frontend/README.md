# Frontend (React + Vite)

## Environment

Copy template and set backend URL:

```bash
cp .env.example .env
```

Set:

- `VITE_API_URL` (example: `http://localhost:8000` for local)

## Local run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Deploy the generated `dist/` directory with `VITE_API_URL` set to your backend domain.
